# Word Shorts - UI/UX PRD

**영어 단어, 이제 쇼츠로 놀면서 배우자**

| 항목 | 내용 |
|------|------|
| 문서 버전 | 0.2.0 |
| 작성자 | Hoseok, Richbot |
| 작성일 | 2026-02-14 |
| 상태 | 🟡 Draft |

---

## 1. Problem

**영어 암기는 필수이지만, 힘들다.**

- 기존 영단어 학습 방식은 지루하고 반복적
- 플래시카드, 단어장은 동기부여가 어려움
- 학습 지속률이 낮음

---

## 2. Solution

**쇼츠를 보면서 영단어를 배우고 암기한다.**

- 30초 쇼츠 형태의 짧은 콘텐츠
- 시각적 + 스토리텔링으로 기억에 남는 학습
- 틱톡/릴스처럼 스와이프하며 자연스럽게 학습

---

## 3. Impact

**최고의 영단어 암기 방법**

- MZ세대에게 익숙한 쇼츠 포맷
- AI 기반 개인화 콘텐츠
- 재미 + 학습의 결합

---

## 4. How It Works

```
[단어 입력]
    │
    ▼
[시나리오 생성] ─── LLM이 단어를 설명하는 스토리 생성
    │
    ▼
[이미지 생성] ───── ComfyUI로 시작 이미지 생성
    │
    ▼
[비디오 생성] ───── 이미지 + 시나리오 → 쇼츠 영상
    │
    ▼
[퍼블리시]
```

---

## 5. 타겟 고객 정의

> ⚠️ **핵심**: 어떤 고객을 타겟팅하느냐에 따라 다른 쇼츠가 되어야 한다.

### 5.1 고객 세그먼트

| 세그먼트 | 특징 | 콘텐츠 스타일 |
|---------|------|-------------|
| **입문자** | 영어 기초, 쉬운 단어 | 간단한 예문, 일상 상황 |
| **토익 준비생** | 시험 대비, 빈출 단어 | 비즈니스 상황, 공식적 표현 |
| **회화 학습자** | 실제 대화, 상황별 표현 | 대화 시나리오, 구어체 |
| **고급 학습자** | 어려운 어휘, 뉘앙스 | 문학적 표현, 미묘한 차이 |

### 5.2 Primary Target (MVP)

- **20-30대 영어 학습자**
- 토익/토플 준비 또는 자기계발 목적
- 쇼츠/릴스 소비에 익숙한 세대

## 6. 단어 DB 설계

### 6.1 필수 속성

| 필드 | 설명 | 예시 |
|------|------|------|
| word | 영단어 | serendipity |
| meaning_en | 영어 정의 | pleasant surprise by chance |
| meaning_ko | 한국어 뜻 | 뜻밖의 행운 |
| difficulty | 난이도 (1-10) | 7 |
| category | 카테고리 | 감정/추상 |
| toeic_freq | 토익 빈출도 | high/medium/low |
| example | 예문 | "Finding this was pure serendipity" |

### 6.2 난이도 기준

| 레벨 | 난이도 | 설명 |
|------|--------|------|
| 1-3 | 초급 | 중학 필수, 일상 기초 |
| 4-6 | 중급 | 고등 수준, 토익 600-800 |
| 7-8 | 고급 | 토익 800+, 수능 고급 |
| 9-10 | 최상급 | GRE/SAT 수준 |

### 6.3 유저 수준 파악

> ⚠️ **유저의 수준을 아는 게 중요**

- 초기 레벨 테스트 (5-10문제)
- 학습 기록 기반 적응형 추천
- 틀린 단어 복습 시스템

---

## 7. 콘텐츠 유형

### 7.1 단어 유형별 접근

| 유형 | 접근 방식 | 예시 |
|------|----------|------|
| **명사** | 이미지로 충분 | apple → 사과 이미지 |
| **동사** | 액션/상황 묘사 | run → 달리는 장면 |
| **형용사** | 비교/대조 | big vs small |
| **추상어** | 스토리텔링 | serendipity → 우연한 발견 시나리오 |

### 7.2 회화 콘텐츠 (확장)

- 특정 상황별 회화 표현
- TTS 활용한 발음 학습
- 실시간 대화 시뮬레이션 (Future)

## 8. User Flow

### 8.1 학습자 플로우

```
[앱 시작]
    │
    ├── [레벨 테스트] ← 첫 사용자
    │
    ▼
[홈 - 쇼츠 피드]
    │
    ├── 스와이프 → 다음 영상
    ├── 좋아요 → 저장
    ├── 탭 → 상세보기
    │
    ▼
[단어 상세]
    │
    ├── 발음 듣기
    ├── 예문 보기
    └── 복습 목록 추가
```

### 8.2 관리자 플로우 (콘텐츠 생성)

```
[단어 선정]
    │
    ▼
[AI 시나리오 생성] → [QA/수정]
    │
    ▼
[이미지 생성] → [QA/재생성]
    │
    ▼
[영상 생성] → [최종 QA]
    │
    ▼
[난이도/카테고리 태깅]
    │
    ▼
[퍼블리시]
```
