## 🎯 프로젝트 개요

Word Shorts는 영단어를 30초 쇼츠 영상으로 학습할 수 있는 서비스입니다.

### 핵심 기능
- 영단어 → AI 시나리오 생성
- 시나리오 → 이미지 생성 (ComfyUI)
- 이미지 + 시나리오 → 쇼츠 영상 생성
